# Ошибка вспомогательной финальной сверки

[Этот запуск](report.json) завершился FAIL в проверяющем выражении: Promise
`window.musicOrbs.snapshot()` помещён внутрь объекта без `await`. CDP сериализовал
его пустым объектом, поэтому сравнение `snapshot.settings` получило undefined.
Это ошибка диагностического выражения, а не измеренное повреждение сессии.
Проверка read-only; данные приложения этим запуском не изменялись.

Повтор использует `(async()=>({snapshot:await window.musicOrbs.snapshot(),…}))()`
и сохраняется отдельно. Этот FAIL не засчитывается как успешная финальная сверка.
