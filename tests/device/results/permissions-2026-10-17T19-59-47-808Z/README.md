# Ограничение этого промежуточного прогона

Тестовые assertions прошли, но сценарий выполнял Main Capture Cancel между
успешным mic grant и `pm revoke`. Capture предварительно остановил микрофон.
Поэтому этот отчёт подтверждает диалоги/индикатор/отмену захвата/restart, но
**не подтверждает отзыв разрешения у активного микрофона**.

Проверка повторена с порядком active microphone → assert активного UUID →
revoke → restart → mic deny → отдельный Capture Cancel. Итоговый отчёт указан
в [матрице FT/CT](../../../functional/results.md). Исторические данные сохранены.
