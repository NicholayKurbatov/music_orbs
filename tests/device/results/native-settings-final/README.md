**21 уникальная проверка настроек прошла**. Это объединение двух прогонов,
а не утверждение об одном полном успешном запуске. Native UI и renderer
между ними не менялись.
[Машиночитаемый итог](report.json) перечисляет источник каждой проверки.

Первые 14 проверок: [отчёт](../native-settings-2026-10-17T20-20-04-528Z/report.json).
Проверены medium/60, четыре пресета, три материала, четыре готовые палитры
и выбор своего цвета. Прогон остановился при поиске кнопки применения HEX:
свайп автоматизации попадал на клавиатуру вместо уменьшенной ScrollView.
Пройденные шаги сохранены; общий статус исходного прогона остаётся fail.

Оставшиеся семь проверок и повторная установка custom palette:
[успешный targeted report](../native-settings-2026-10-17T20-29-43-718Z/report.json).

30 FPS и high quality. При исправленном свайпе внутри реальных bounds панели
кнопка применения доступна с открытой клавиатурой:
[PNG](../native-settings-2026-10-17T20-29-43-718Z/custom-color-before-apply.png),

Прежние неуспешные попытки не удалены.

Каждое изменение выполнено нативными taps/swipes/text, подтверждено живой
сценой и native atomic store. Seed, controls и revisions всех четырёх форм
точно совпали до/после каждого действия: касания панели не деформируют сцену.
Baseline settings восстановлены служебной командой и перезапуском приложения;
этот cleanup исключён из доказательства UI. Reset отдельно проверен G2.
