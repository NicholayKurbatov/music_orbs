## 2. Контрактные и архитектурные проверки

| ID | Контракт | Проверка |
|---|---|---|
| CT-01 | ShapeFactory | Одинаковые shapeId/seed/version/count дают одинаковую базу; NaN и count вне профиля отклоняются |
| CT-02 | DeformationField | Snapshot — отделённая копия; локальная деформация и Reset сохраняют инварианты revision |
| CT-03 | MotionSignal | Диапазоны, nullable BPM, конечность, sourceSessionId и монотонность времени |
| CT-04 | Bridge v1 | Общие Kotlin/TS JSON fixtures, wire enum/Vec3 mapping, неверная версия/oversized/stale envelope |
| CT-05 | SessionStore | Атомарность, миграции, stale save, corrupted snapshot, отсутствие файла |
| CT-06 | Clean Architecture | Нет Android/Three.js/DOM/IO в domain; application не импортирует infrastructure/presentation |
| CT-07 | Lifecycle | Повторные close/dispose/stop безопасны; pending read/request завершаются, listeners освобождаются |
| CT-08 | Upstream adaptation | Сохранены notices; извлечённые генераторы детерминированы, shaders компилируются, capture выдаёт ожидаемый PCM |

## 3. Производительность и визуальная оценка

- По 10 минут на пресет/quality: p50/p95 кадра, FPS, пропуски, particle/control count.
- По 30 минут: память, батарея, температура и throttling; одинаковые условия яркости/питания.
- Проверить WebGL context loss/recovery и фон/возврат без потери сохранённой формы.
- Музыка: ambient, электронная, инструментальная, нерегулярный ритм, тишина.
- Визуальная оценка человеком: объём, приятность касаний, отсутствие резких ускорений и чрезмерного bloom.

Матрица устройства: модель, Android, WebView, источник/версия приложения,
тип выхода (динамик/проводные/Bluetooth наушники), разрешения, фактический PCM,
результат сценария и артефакт измерений. Spotify и Яндекс Музыку проверять отдельно.
