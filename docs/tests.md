# Функциональные сценарии и приёмка

Статус: план тестирования. Приложение не реализовано; перечисленные сценарии
не считаются выполненными. Сейчас проверяется только целостность документации
и архитектурных деклараций, а не графика, звук или APK.

## 3. Производительность и визуальная оценка

- По 10 минут на пресет/quality: p50/p95 кадра, FPS, пропуски, particle/control count.
- По 30 минут: память, батарея, температура и throttling; одинаковые условия яркости/питания.
- Проверить WebGL context loss/recovery и фон/возврат без потери сохранённой формы.
- Музыка: ambient, электронная, инструментальная, нерегулярный ритм, тишина.
- Визуальная оценка человеком: объём, приятность касаний, отсутствие резких ускорений и чрезмерного bloom.

Матрица устройства: модель, Android, WebView, источник/версия приложения,
тип выхода (динамик/проводные/Bluetooth наушники), разрешения, фактический PCM,
результат сценария и артефакт измерений. Spotify и Яндекс Музыку проверять отдельно.

## 4. Критерий завершения тестирования

Все основные FR имеют успешные сценарии; условные источники имеют документированный
результат на выбранной матрице. Открытые численные допуски согласованы до измерений.
Нельзя заменять фактические device results утверждениями из upstream README.
Статическая проверка заглушек не подтверждает прохождение FT/CT приложения.

## 5. Проверки текущего каркаса (2026-10-17)

- Проверка существования обязательных документов и локальных Markdown-ссылок: успешно.

Проверка импортов — статическая проверка перечисленных правил, а не доказательство
всех архитектурных свойств будущей реализации. Зависимости приложения не установлены;
