# Pointer presentation adapter

Перевод pointer-событий в Stroke в локальных координатах объекта.
DOM и raycasting допускаются только в адаптере. Приоритет — скульптура;
OrbitControls из сторонних примеров не должен перехватывать этот жест.
Реализация picking и удержания локальной плоскости контакта пока отсутствует.
