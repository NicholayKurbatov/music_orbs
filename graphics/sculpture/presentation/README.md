# Адаптер указателя

Перевод pointer-событий в Stroke в локальных координатах объекта.
DOM и raycasting допускаются только в адаптере. Приоритет — скульптура;
OrbitControls из сторонних примеров не должен перехватывать этот жест.
`PointerController.ts` удерживает первый pointer через pointer capture,
игнорирует остальные и завершает жест при up/cancel/lost capture. Центр поля
фиксируется в object space; drag идёт по плоскости контакта с преобразованием
inverse object matrix в ThreeRenderer.pick. Чувствительность применяется
только SculptureScene; pointer adapter её не умножает повторно.

Касания панели не поступают canvas. Малый начальный импульс даёт короткому
касанию постоянное локальное смещение; drag добавляет смещение к той же опоре.
Ошибки лимитов поля отображаются в status-сообщении.
