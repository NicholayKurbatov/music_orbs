# Upstream adaptation boundary

План адаптации найденных проектов указан в docs/reuse.md в корне проекта.
Здесь будут обёртки извлечённых генераторов и шейдерных фрагментов.
Сторонний исходный код пока не скопирован; прямые импорты UI сторонних демо
в domain/application не допускаются. Метаданные происхождения: third_party/README.md.
