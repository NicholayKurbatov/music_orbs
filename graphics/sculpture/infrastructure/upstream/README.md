# Граница процедурных генераторов

План адаптации найденных проектов указан в docs/reuse.md в корне проекта.
ProceduralShapeFactory реализует ShapeFactory. Из thinking-orbs адаптирована
только функция fibDir для детерминированной сферы; координаты деформации,
складчатая открытая Ribbon, объёмный Cloud и вложенные квадратные рамки Pixel
созданы для контрактов Music Orbs. Canvas/React UI демо не переносился.
Метаданные происхождения: [third_party](../../../../third_party/README.md).
